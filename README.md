# 📚 Progra-IV-2025: Sistema Académico

¡Bienvenido al repositorio del curso **Programación Computacional IV - 2025**!  
Aquí encontrarás clases, ejemplos y un proyecto académico completo utilizando tecnologías modernas como **Laravel**, **Vue.js**, **Bootstrap** y **IndeedDB**.

---

## 🚀 Tecnologías Utilizadas

- ⚙️ **Backend:** Laravel 10
- 🎨 **Frontend:** Vue.js + Bootstrap 5
- 🗄️ **Base de Datos:** IndeedDB
- 📦 **Gestor de dependencias:** npm + Composer

---

## 🧾 Descripción del Proyecto

Este sistema académico permite la gestión de formularios para estudiantes, simulando un entorno escolar real.  
Incluye funciones como:

- Registro de estudiantes 📄  
- Validaciones con Vue.js ✔️  
- Estilización moderna con Bootstrap ✨  
- Conexión eficiente a base de datos NoSQL (IndeedDB) 🔗
